# VR-_-HI3559AV100
以海思HI3559为主控的VR一体机眼镜主板
基于海思芯片HI3559AV100完整的VR眼镜8层PCB设计，集成4颗DDR4(最大8G)+UFS,2片视涯1.3‘MicroOled+4颗豪威4lane摄像头，集成4G/WIFI,配备VR瞳距调节电机，创新性引入UWB定位芯片，让多人室内VR游戏得以实现互动性提升，hdmi等外部接口一应俱全。外壳参考苹果Vision Pro设计
作品仅供参考，请勿直接打板，整个成本极高，也还有很多做的不完善的地方，
