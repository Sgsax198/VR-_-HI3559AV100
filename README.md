# VR‑HI3559AV100
<p align="center">
基于海思 HI3559AV100 的VR一体机眼镜主板开源硬件项目
</p>

> [!WARNING]
> **作品仅供学习参考，请勿直接打板！**
> 整套硬件成本较高，所有芯片及器件均作了国产化

完整 **8层PCB** VR眼镜硬件方案，主控采用海思HI3559AV100，面向多人室内VR交互场景；外壳结构参考苹果Vision Pro。

## 📦 核心硬件规格
- 4颗 DDR4，最大支持 **8GB** + UFS高速存储
- 2片视涯 1.3英寸 Micro‑OLED 显示屏幕
- 4颗豪威 4‑Lane 摄像头
- 集成4G / Wi‑Fi无线通信
- VR电动瞳距调节电机
- UWB定位芯片，实现多人室内VR游戏互动
- 预留HDMI等丰富外部接口
